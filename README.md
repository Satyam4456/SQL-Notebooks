# SQL Projects Portfolio

Welcome! This repository serves as a workspace and portfolio for my hands-on SQL projects as a Data Analyst. Here, I store database modeling exercises, normalization pipelines, analytical queries, and data cleaning scripts.

---

## 📁 How This Repository Is Organized

Projects are stored in individual folders. Each project folder contains:
* **Documentation (`.md`):** A detailed walkthrough of the project, including dataset background, problem statement, and SQL code.
* **SQL Scripts / Notebooks:** Raw query files and schemas.
* **Supporting Assets:** ER diagrams, flowcharts, or export files where applicable.

Feel free to browse through the directories above to explore specific projects.

---

## 🛠 Skills & Tools Covered

* **Database Systems:** MySQL, PostgreSQL
* **Core Concepts:** Data Normalization (1NF–3NF), Star & Snowflake Schema Modeling, DDL/DML, Foreign Key Relationships
* **Querying Techniques:** Complex Joins, CTEs, Window Functions, Aggregations, Stored Procedures
* **Environment:** VS Code, Git/GitHub
